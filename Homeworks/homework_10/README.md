Задание 1: Rabin–Karp. Используется rolling hash: строка длины m кодируется как сумма символов, умноженных на степени основания base по модулю mod. При сдвиге окна вычитается вклад уходящего символа и добавляется новый, что дает O(1) на сдвиг без пересчета всей подстроки. Хеш подстроки сравнивается с хешем образца; при совпадении дополнительно сверяется сама подстрока, чтобы отсеять коллизии. Итоговая сложность O(n + m) по времени и O(1) по памяти, кроме хранения ответа.

Задание 2: Knuth–Morris–Pratt. Сначала вычисляется массив lps (длина наибольшего собственного суффикса, являющегося префиксом) за O(m). В процессе поиска при несовпадении символов индекс в тексте не откатывается назад: переход происходит по lps, тем самым повторно не сравниваются уже проверенные префиксы. Итоговая сложность O(n + m) по времени и O(m) по памяти на lps.

Задание 3: LCS. Строится таблица DP (n+1)×(m+1), где каждая ячейка хранит длину LCS для соответствующих префиксов. Переход: если символы совпадают, увеличиваем диагональ на 1; иначе берем максимум из соседей сверху/слева. Ответ восстанавливается обратным обходом таблицы: при совпадении символ добавляется в результат и оба индекса сдвигаются вверх-влево, иначе двигаемся в сторону большего значения. Сложность O(n·m) по времени и O(n·m) по памяти.
